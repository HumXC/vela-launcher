# Official Minecraft default skins

These nine 64 × 64 PNGs are the unmodified wide default skins from Minecraft Java Edition **1.21.4**, extracted from `assets/minecraft/textures/entity/player/wide/<name>.png` in the official client JAR. They provide bundled offline avatar fallbacks; no third-party avatar CDN is required. The base face occupies `(8, 8)` through `(15, 15)`; its transparent outer layer occupies `(40, 8)` through `(47, 15)` (zero-based pixels).
